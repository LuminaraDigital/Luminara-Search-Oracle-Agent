# MCP entitlements and credits

## Status

Accepted (APS A1, A4, A7)

## Decision

| Class | Who | Tools |
|-------|-----|-------|
| Free MCP | Growth+, Agency | whoami, projects, context, reports |
| Paid research | Agency apiAccess OR BYOK DFS | keywords, SERP, domain, backlinks, visibility |
| Agency API | Agency only | /api/oracle, /api/audit, /api/tools |

Tool descriptions state credit class. Paid success appends research log. Skills check log within 30 days before re-spend.

## Alternatives considered

- All MCP behind Agency: too high a bar for plugin adoption.
- Separate credit ledger: defer; reuse quota middleware.
