Deploy the Jetton

Nothing on this page can spend your Toncoin. Each transaction is shown in your wallet app first and only happens if you approve it there. This page never asks for a recovery phrase or a private key. If anything asks you for one, stop.

The token

1. Connect the wallet that will own the token

The connected wallet becomes the admin and receives the whole supply. The contract only lets its admin launch it, so the supply cannot end up at an address nobody controls.

2. Review and deploy

This is mainnet. A deployed Jetton cannot be changed, renamed at its address, or recalled. Read each line before you tick it.
