Luminara MCP

Connect Cursor, Claude, or Codex to https://luminarasuite.com/api/mcp with a Growth or Agency API key (Authorization: Bearer lm_live_...).

Create keys via signed-in POST /api/api-keys. Free tools: projects, context, reports. Paid research needs Agency or DataForSEO BYOK (x-provider-key).

Plugin and skills live in the repo under plugins/luminara/.

Setup

{
  "mcpServers": {
    "luminara": {
      "url": "https://luminarasuite.com/api/mcp",
      "headers": {
        "Authorization": "Bearer lm_live_YOUR_KEY"
      }
    }
  }
}
