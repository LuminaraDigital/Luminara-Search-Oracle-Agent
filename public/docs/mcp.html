Luminara MCP

Connect your coding app to https://luminarasuite.com/api/mcp with a key from any plan (Authorization: Bearer lm_live_...).

MCP is on every plan. Free allows 100 calls a day and Starter 300; Growth and Agency have no daily cap. The included tools are projects, context, and reports. Browser tools need Growth or Agency. Paid research needs the Agency plan, or your own research login.

The connector is included with Growth and Agency.

Setup

{
  "mcpServers": {
    "luminara": {
      "url": "https://luminarasuite.com/api/mcp",
      "headers": {
        "Authorization": "Bearer lm_live_YOUR_KEY"
      }
    }
  }
}

Changes

October 2026: send one tools/call per request. A JSON-RPC batch with more than one tools/call is refused with HTTP 400 and error -32600. A batch may still carry initialize, tools/list and ping next to its one call.
