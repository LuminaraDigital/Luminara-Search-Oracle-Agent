Luminara MCP

Connect Grok, Claude, Claude Code, ChatGPT, Antigravity or Cursor to https://luminarasuite.com/api/mcp and sign in with your Luminara account. No API key is needed.

MCP is on every plan. Free allows 100 calls a day and Starter 300; Growth and Agency have no daily cap. The included tools are projects, context, and reports. Browser tools need Growth or Agency. Paid research needs the Agency plan, or your own research login.

The connector is on every plan. Free and Starter use the daily MCP cap. Paid research stays on Agency.

Connect

Add the endpoint, then sign in. Your app registers itself, a Luminara consent page shows who is asking, and you press Allow. Agents connected this way use the free tools only. Settings lists every connection with a Disconnect button.

  • Grok: grok.com/connectors, New Connector, Custom, paste the endpoint.
  • Claude Code: claude mcp add --transport http luminara https://luminarasuite.com/api/mcp, then /mcp to sign in. Or install the Luminara plugin: claude plugin marketplace add LuminaraDigital/Luminara-Search-Oracle-Agent, then claude plugin install luminara@luminara.
  • Claude and ChatGPT: add a custom connector with the endpoint.
  • Antigravity: add the server below to mcp_config.json, then choose Authenticate. 
    { "mcpServers": { "luminara": { "serverUrl": "https://luminarasuite.com/api/mcp" } } }
  • Cursor: Add to Cursor, or put the server below in .cursor/mcp.json. 
    { "mcpServers": { "luminara": { "url": "https://luminarasuite.com/api/mcp" } } }

Agents

Three named agents answer in every host, from what Luminara has stored for a project. They are free, and they read only: none of them crawls, re-checks or changes anything.

  • Luminara Auditor (ask_auditor): the findings on record, worst first, with the date of the last audit.
  • Luminara Fixer (ask_fixer): the fix drafts stored for the site, and the open findings that have none.
  • Luminara Coach (ask_coach): the decision set for this week, or a candidate when none is set.

Hosts that list MCP prompts show the same three as auditor, fixer and coach. With nothing stored yet, each one points to the free Instant Audit.

When an action needs your approval, the agent gives you a luminarasuite.com link. Sign in, read what it wants to do, and choose Approve once or Deny. The link works for 30 minutes.

API key (scripts and servers)

For a script with no browser, send a Luminara API key as a Bearer token instead.

{
  "mcpServers": {
    "luminara": {
      "url": "https://luminarasuite.com/api/mcp",
      "headers": {
        "Authorization": "Bearer lm_live_YOUR_KEY"
      }
    }
  }
}
