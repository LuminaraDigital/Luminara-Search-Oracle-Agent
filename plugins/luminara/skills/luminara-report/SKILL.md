# Luminara Report

## Rules

- `list_reports` first; pass `reportId` to replace the same subject/period.
- Title names subject + period. Summary: verdict, one top action, key numbers (under 2500 chars).
- HTML: inline CSS only, no scripts, no backticks, no `${`, must end with `</html>`.
- After save: at most three short bullets, then `Read the full report: <url>`.

## Starter shell

```html
<!doctype html>
<html lang="en"><head><meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>TITLE</title>
<style>
:root{--bg:#fff;--fg:#0a0a0a;--fg-2:#454545;--rule:#ebebeb;--accent:#0a0a0a}
body{background:var(--bg);color:var(--fg);margin:0;padding:0 24px 80px;font:18px/1.65 system-ui,sans-serif}
.shell{max-width:720px;margin:0 auto}h1{font-size:40px;letter-spacing:-.03em;margin:40px 0 12px}
h2{font-size:24px;margin:40px 0 12px}.finding{margin:0 0 16px;padding:0;list-style:none}
.finding li{margin:0 0 6px;color:var(--fg-2)}.finding b{color:var(--accent)}
</style></head><body><div class="shell">
<header><h1>TITLE</h1><p class="byline">Luminara report</p></header>
<article>
<h2>Verdict</h2>
<ul class="finding"><li><b>Status:</b> ONE SENTENCE</li><li><b>Fix:</b> ONE ACTION</li></ul>
<h2>What to do next</h2>
<ol><li>FIRST STEP</li></ol>
<h2 id="how-this-report-was-made">How this report was made</h2>
<p>Generated by a Luminara product skill via MCP.</p>
</article></div></body></html>
```

Apply deslop: short Status/Fix/Why bullets, specific numbers, no filler.
