## 8. How to Generate Additional Keys Anytime

You can generate more keys at any time via the command line:

```bash
# Generate 10 new 3-day Growth passes:
npm run keys:generate -- --plan=growth --days=3 --count=10

# Generate 5 new 30-day Pro/Agency keys and export to JSON:
npm run keys:generate -- --plan=agency --days=30 --count=5 --export=agency-keys.json

# Generate 100 Starter keys:
npm run keys:generate -- --plan=starter --days=30 --count=100 --export=starter-batch.json
```

## 9. How Users Redeem Keys

Users can activate any of these keys in 3 frictionless ways:

1. **Web App / TMA Paywall Modal**:
   - Open Paywall → Tap **"I have a license key"** → Enter Key → Tap **[ Activate ]**.
2. **Telegram Bot Chat**:
   - Send `/license YOUR-KEY` directly to your bot (e.g. `/license LUM-GROWTH-3DAY`).
3. **Settings / Account Panel**:
   - Tap **"Redeem License Key / 3-Day Pass"** → Enter Key → Tap **[ Activate ]**.
