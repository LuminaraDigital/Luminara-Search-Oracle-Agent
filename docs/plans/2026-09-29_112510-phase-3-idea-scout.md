## Goal

Give aspiring founders (no owned domain yet) a Telegram Mini App front door that turns an idea sentence into a structured AEO/visibility card, then a clear handoff into Instant Audit once they have a URL - ValidatorAI / IdeaBrowser-style onboarding without inventing rankings or SERP percentages.

## Context and assumptions

- Phase 0-1 honesty + guest Instant Audit + teasers are shipped (`specs/0007`, #14/#15).
- Phase 2 referrals / missions / Visibility Level are on `main` (`specs/0009`, #19, D1 `0012`).
- Locked sequence: Phase 3 = Idea Scout + continuum into Instant Audit; Niche Pulse may ship in the same PR as a thin cut or as a follow-up if bot cron is heavy (`suite-phases-2-plus-execution-plan.md`).
- Hosted spend still requires Telegram `initData` or Firebase session inside `FREE_DAILY_LIMIT` (+ referral credits). Anonymous browsers do not burn hosted keys.
- Non-goals still hold: no GameFi, no fake scores/ranks, no unlimited hosted burn, no Ahrefs / IdeaBrowser paid-depth clone.

## Approach and trade-offs

**Approach (recommended thin cut):**

1. **Entry UX** - New Suite / TMA surface "Idea Scout" (nav + deep link `startapp=idea` or `idea_<slug>`). Form: idea sentence (required), niche/category (optional), up to 3 competitor URLs (optional, public-hostname rules only).
2. **Card generation** - Worker route produces a typed JSON card from hosted LLM (metered) + optional evidence:
  - problem (1-2 sentences)
  - who asks AI (persona / prompt patterns - labeled as model inference, not measured)
  - competitor citation snapshot (only from fetched public pages / search when URLs or niche search ran; otherwise `not_measured` / empty evidence)
  - 3 content bets (hypotheses, not rankings)
  - site checklist (pre-domain: llms.txt, entity pages, FAQ, schema - checklist items, not scores)
3. **Honesty** - Card schema forbids percentage fields and measured badges unless backed by the same evidence rules as Instant Audit. Missing fetches to `not_measured`. No invented SERP %.
4. **Persist + continuum** - D1 table for idea cards (account-scoped when signed in; short-lived guest token otherwise). "I have a domain" CTA prefills Instant Audit via existing `audit_<domain>` / `scan_<domain>` start params and links the idea row to the first scout run id when available.
5. **Niche Pulse (thin or follow-up)** - Schema + bot `/pulse` or daily cron message shape storing last niche + one tip. If Worker cron / scheduling is heavy, ship message template + storage in this PR and enable cron in a tiny follow-up.

**Trade-offs:**

| Choice | Why |
|--------|-----|
| Worker-minted card, not client-only LLM | Metering, honesty attestation, no client-spoofed "measured" claims |
| Checklist + hypotheses, not scores | Matches Suite honesty; avoids Fake IdeaBrowser theater |
| Pulse optional-same-PR | Unblocks Idea Scout value if cron is blocked; pulse is retention, not the front door |
| Reuse Instant Audit hostname guards | Same SSRF / public-host rules as guest scout |
